## 🚀 5 分钟快速上手

### 1️⃣ 注册账号

访问：https://www.natfrp.com/
点击右上角"注册"（免费）

### 2️⃣ 下载客户端

**Mac 用户**：
- 访问：https://www.natfrp.com/tunnel/download
- 下载 Mac 版客户端

**或使用命令行版**：
```bash
wget https://nya.globalslb.net/natfrp/client/launcher-unix.sh -O launcher.sh
chmod +x launcher.sh
```

### 3️⃣ 创建隧道

1. 登录控制台：https://www.natfrp.com/user/
2. 点击左侧 **"隧道列表"** -> **"创建隧道"**
3. 填写配置：

```
隧道名称: perplexity-api
隧道类型: HTTP
本地IP:   127.0.0.1
本地端口: 3000
节点:     选择免费节点（推荐"国内-广州"或离你最近的）
```

4. 点击"创建"

### 4️⃣ 启动服务

**步骤 1：启动 API 服务器**
```bash
cd /Users/chihairou/development/wisestep/api
npm start
```

**步骤 2：启动 Sakura Frp**

方式 A - 使用客户端（推荐）：
1. 打开下载的客户端
2. 登录你的账号
3. 选择刚创建的隧道
4. 点击"启动"

方式 B - 使用命令行：
```bash
# 获取访问令牌：https://www.natfrp.com/user/profile
./launcher.sh <你的访问令牌>
```

### 5️⃣ 获取公网地址

启动成功后，你会看到公网地址：
```
✅ 隧道已启动
📡 公网地址: http://your-name.natfrp.cloud
```

或者如果开启了 HTTPS：
```
📡 公网地址: https://your-name.natfrp.cloud
```

### 6️⃣ 测试访问

```bash
# 测试 API 是否可用
curl -X POST https://your-name.natfrp.cloud/api/chat \
  -H "Content-Type: application/json" \
  -d '{"messages": [{"role": "user", "content": "你好"}]}'
```

## 📱 在智步 App 中使用

修改 API 地址：

```typescript
// lib/perplexity.ts
const API_URL = 'https://your-name.natfrp.cloud/api/chat';

export async function chatWithPerplexity(messages: Array<{role: string, content: string}>) {
  const response = await fetch(API_URL, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ messages })
  });

  return await response.json();
}
```

## 🔧 开机自启（可选）

如果想让服务开机自动启动：

### 1. 创建启动脚本

```bash
# 编辑 ~/start-api-server.sh
#!/bin/bash
cd /Users/chihairou/development/wisestep/api
npm start &

# 等待几秒
sleep 5

# 启动 Sakura Frp（需要替换为你的令牌）
/path/to/launcher.sh <你的访问令牌>
```

### 2. 添加到开机启动

```bash
chmod +x ~/start-api-server.sh

# Mac 创建 LaunchAgent
# 或使用 pm2：
pm2 start npm --name "api-server" -- start
pm2 startup
pm2 save
```

## ⚠️ 注意事项

1. **Mac 需要保持运行** - 关机或休眠后无法访问
2. **域名固定** - 创建后域名不会变，可以放心分享
3. **流量限制** - 免费节点可能有流量限制（一般够用）
4. **节点选择** - 选择离你和用户都近的节点，速度更快

## 🆘 常见问题

### Q: 隧道连接失败？
**A**: 检查本地服务器是否运行：
```bash
curl http://localhost:3000/health
```

### Q: 提示"节点繁忙"？
**A**: 更换其他免费节点，或使用付费节点

### Q: 访问速度慢？
**A**:
1. 更换离用户更近的节点
2. 检查本地网络
3. 考虑升级到付费节点（带宽更大）

### Q: 免费版够用吗？
**A**: 如果只是给朋友使用，或低频调用，免费版完全够用

### Q: 需要备案吗？
**A**: 使用 Sakura Frp 提供的域名无需备案
