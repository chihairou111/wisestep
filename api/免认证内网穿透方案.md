# 免实名认证的内网穿透方案

以下方案都**不需要实名认证**，适合快速部署。

---

## 🥇 方案 1: LocalTunnel（推荐）

### 特点
- ✅ 完全免费
- ✅ 无需注册
- ✅ 一行命令启动
- ✅ 开源项目
- ⚠️ 域名每次重启会变（但可以指定子域名）

### 安装

```bash
sudo npm install -g localtunnel
```

### 使用

```bash
# 方式 1: 使用一键脚本
cd api
./start-with-localtunnel.sh

# 方式 2: 手动启动
# 终端 1: 启动 API 服务器
npm start

# 终端 2: 启动 LocalTunnel
lt --port 3000 --subdomain wisestep-api
```

会得到域名：
```
https://wisestep-api.loca.lt
```

### 更新配置

修改 `lib/config.ts`：
```typescript
export const PERPLEXITY_PROXY_URL =
  __DEV__
    ? 'http://localhost:3000/api/chat'
    : 'https://wisestep-api.loca.lt/api/chat';
```

## 🥈 方案 2: Bore（超简单）

### 特点
- ✅ 完全免费
- ✅ 无需注册
- ✅ 超级简单
- ✅ Rust 编写，速度快
- ⚠️ 国外服务器，可能稍慢

### 安装

```bash
# Mac
brew install bore-cli

# 或下载二进制文件
# https://github.com/ekzhang/bore/releases
```

### 使用

```bash
# 终端 1: 启动 API 服务器
cd api
npm start

# 终端 2: 启动 Bore
bore local 3000 --to bore.pub
```

会显示：
```
listening at bore.pub:xxxxx
```

访问地址：`http://bore.pub:xxxxx/api/chat`

---

## 🥉 方案 3: Serveo（基于 SSH）

### 特点
- ✅ 完全免费
- ✅ 无需注册
- ✅ 基于 SSH，安全
- ✅ 可以指定子域名
- ⚠️ 有时不稳定

### 使用（无需安装）

```bash
# 终端 1: 启动 API 服务器
cd api
npm start

# 终端 2: 启动 Serveo
ssh -R 80:localhost:3000 serveo.net
```

会显示：
```
Forwarding HTTP traffic from https://xxxxx.serveo.net
```

指定子域名：
```bash
ssh -R wisestep:80:localhost:3000 serveo.net
```

会得到：`https://wisestep.serveo.net`

---

## 🏆 方案 4: Cloudflare Tunnel（最稳定）

虽然配置稍复杂，但**不需要实名**，而且最稳定。

### 安装

```bash
brew install cloudflare/cloudflare/cloudflared
```

### 快速使用（临时域名）

```bash
# 终端 1: 启动 API 服务器
cd api
npm start

# 终端 2: 启动 Cloudflare Tunnel
cloudflared tunnel --url http://localhost:3000
```

会自动分配域名：`https://xxx.trycloudflare.com`

⚠️ **注意**：Cloudflare 域名在国内访问可能不稳定。

## 🚀 推荐使用 LocalTunnel

**最简单，最适合国内使用**

### 完整步骤

1. **安装**
   ```bash
   sudo npm install -g localtunnel
   ```

2. **启动 API 服务器**
   ```bash
   cd /Users/chihairou/development/wisestep/api
   npm start
   ```

3. **启动 LocalTunnel**
   ```bash
   # 新开一个终端
   lt --port 3000 --subdomain wisestep-api
   ```

4. **获取地址**
   ```
   your url is: https://wisestep-api.loca.lt
   ```

5. **首次访问验证**
   - 首次访问时会跳转到验证页面
   - 点击 "Click to Continue"
   - 通过后就可以正常使用了

6. **更新 App 配置**

   编辑 `lib/config.ts`：
   ```typescript
   export const PERPLEXITY_PROXY_URL =
     __DEV__
       ? 'http://localhost:3000/api/chat'
       : 'https://wisestep-api.loca.lt/api/chat';
   ```

7. **测试**
   ```bash
   curl -X POST https://wisestep-api.loca.lt/api/chat \
     -H "Content-Type: application/json" \
     -d '{"messages": [{"role": "user", "content": "你好"}]}'
   ```

## 💡 使用建议

### 开发测试
使用 **LocalTunnel** 或 **Bore**，快速启动测试。

### 长期使用
考虑：
1. 租一台国内云服务器（阿里云/腾讯云）
2. 部署 API 服务器到云服务器
3. 获得固定 IP 和域名

每月成本：~30-50 元

## 🆘 故障排查

### LocalTunnel 无法连接
```bash
# 检查服务器是否运行
curl http://localhost:3000/health

# 重启 LocalTunnel
# Ctrl+C 停止后重新运行
lt --port 3000 --subdomain wisestep-api
```

### 首次访问需要验证
- 这是正常的安全机制
- 点击 "Click to Continue" 即可
- 验证一次后不会再要求

### 域名失效
- LocalTunnel 域名可能会过期
- 重启 `lt` 命令即可获得新域名
- 或指定固定子域名（可能被占用）

---

**推荐：先用 LocalTunnel 测试，稳定后再考虑云服务器部署。**
